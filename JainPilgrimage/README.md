# Jain Pilgrimage — Wayanad, Kerala

A responsive, single-page visitor guide to Wayanad's Jain heritage. Explore three featured temples, additional local listings, historic basadis, a suggested day route, travel guidance, and links to further reading.

## Features

- Responsive layout with a mobile navigation menu.
- Filterable place cards for historic basadis and living temples.
- Accessible photo gallery with an expanded-image dialog.
- Suggested route with a link to directions in Google Maps.
- Temple listings, travel notes, and links to tourism and heritage sources.
- Reduced-motion styling and accessible labels for interactive elements.

## Getting started

No build step or package installation is required. Open `index.html` directly in a browser, or serve the project directory with any static HTTP server.

The page loads images and links to maps and other resources hosted by external services, so an internet connection is needed for those features.

## Tests

The test suite uses Node.js's built-in test runner. With Node.js 18 or later installed, run:

```sh
npm test
```

The tests check page structure, accessibility-related markup, navigation, place filtering, gallery behavior, and the linked temple directory.

## Project structure


## Travel note

This guide is informational and is not an exhaustive directory. Temple hours, access, and road conditions can change; confirm details locally before travelling. Treat representative images as illustrative rather than verified photographs of the named sites, and follow local guidance at places of worship and historic remains.
